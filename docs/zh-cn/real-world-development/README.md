通过贴近实际的场景、完整应用和共享积压工作，了解 GitHub Copilot 在整个软件开发生命周期中的应用。你将通过迭代来规划更改、编写代码、测试行为、审查拉取请求并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家以开发者为主题、为桌游提供众筹服务的虚构公司。团队积压工作已整理为 GitHub 议题，等你领取。其中包括筛选和分页等功能工作，以及无障碍支持和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择最适合你的构建环境。每个工作坊都有独立的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作处理 Canvas，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体、引导其工作、监控进度并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。通过 Copilot Chat 代理模式、MCP 服务器和自定义智能体开展工作，无需离开编辑器。
